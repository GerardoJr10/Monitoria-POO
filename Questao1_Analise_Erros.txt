QUESTÃO 1 - ANÁLISE DE ERROS DA CLASSE PRODUTO
================================================

1. Linha 7 — codigo = "A100";
   Erro de tipo: "codigo" é int, mas recebe uma String. Não compila.

2. Linha 8 — nome = nome;
   Erro de lógica (shadowing): o parâmetro "nome" esconde o atributo da
   classe. O atributo da instância nunca é inicializado.
   Correto: this.nome = nome;

3. Linha 13 — System.out.println("Produto: " + nome); dentro de método static
   Erro de compilação: método estático não pode acessar atributo de
   instância (nome não é static).

4. Linhas 16-17 — setCodigo tentando alterar "codigo"
   Erro de compilação: "codigo" é final, só pode ser atribuído uma vez
   (no construtor).

5. Linhas 20-21 — public void getPreco() { return preco; }
   Erro de compilação: método é void, mas tenta retornar um double.
   Deveria ser: public double getPreco()

6. Linha 26 — p1.preco = 150.0;
   Erro de compilação: "preco" é private (inacessível fora da classe) e
   static (não deveria ser acessado via instância, e sim via Produto.preco).

7. Linha 27 — p1.codigo = 500;
   Erro de compilação: viola o modificador final (mesmo problema do erro 4).

8. Problema conceitual — "preco" como static
   Do ponto de vista de modelagem, cada Produto deveria ter seu próprio
   preço. Sendo static, o valor é compartilhado por todas as instâncias,
   o que não faz sentido para este domínio.
